## 修正内容
### 問題文の整理（簡潔化・前提の補強）
- [ターゲット]問題文が長くて読みにくい問題 | [修正内容]何を聞かれているかパッとわかるように短く整理する
- [ターゲット]主語や前提知識（文脈）が抜けていて何を指しているかわからない問題 | [修正内容]冒頭に【分野名】や主語を補い、カード単体で意味が通るようにする
+ [ターゲット]1つの問いで2つ以上の要素を同時に聞いている問題 | [修正内容]最も重要・本質的な1つの要素のみを聞く形に絞り込む
### 想起の強化（曖昧さの排除・記憶定着）
- [ターゲット]答えの候補がいくつも思い浮かんでしまう曖昧な問題 | [修正内容]求める要素（定義・人名・数値など）を明確にして条件を絞り込む
+ [ターゲット]Yes/No（〇×）や2択で勘で正解できてしまう問題 | [修正内容]「理由」「具体的な名称」などを自力で説明・想起させる問い方に変える
+ [ターゲット]「〜とは何か？」という漠然とした定義問題 | [修正内容]「〜〜という特徴を持つ仕組みは何か？」のように、キーワードそのものを想起させる問い（逆引き形式）にする
### 解答文の改善（視認性・構造化）
- [ターゲット]解答が長くて覚えにくい | [修正内容]大事なキーワードがすぐ目に入るように短くまとめる
- [ターゲット]理由や補足が混ざって正解の核が埋もれている解答 | [修正内容]「結論（キーフレーズ）」を1行目に置き、補足や理由は「※補足: 〜」と分けて記載する

## 修正時のルール
* ★重要: 元のカードの "id" は絶対に書き換えず、そのまま維持してください（元のカードと正しく照合・更新するため）。
- 元の意味や正しい内容（事実関係）は勝手に変えない

【出力形式】
改善した全件を以下のJSON形式で出力してください。余計な前置きや後置きは含めず、純粋なJSONのみを返してください。
```json
[
  {
    "id": "元のカードのID",
    "question": "改善後の問題文",
    "answer": "改善後の解答文"
  }
]
```

```vars
[
  { "name": "既存カードリスト", "required": true },
  { "name": "改善要望" }
]
```
