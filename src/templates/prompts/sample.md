【プロンプトテンプレート記法・連動仕様（アプリ側の解釈ルール）】
作成するテンプレートは、本アプリのパーサー仕様に準拠するよう以下のルールに従って記述してください。

1. 変数の記法

* 必須変数: `{{*変数名}}`（未入力時に警告を出してコピーを防止します）
* 省略可能変数: `{{変数名}}` または `{{変数名|}}`（ユーザーが未入力の場合、その変数が含まれる行全体が出力から自動消去されます）
* 既定値付き変数: `{{変数名|既定値}}`（未入力時は指定した既定値が自動代入されます）
* 変数メタデータブロック（```vars）: テンプレート末尾に ```` ```vars ```` ブロックを配置することで、変数のフォーム並び順・必須・既定値を一括定義できます（本文中はシンプルな `{{変数名}}` だけで記述可能になります。コピー時は自動除去されます）。

2. 行の連動消去タグ `((変数名))`

* 行末に `((変数名))` を付与すると、対象の変数が省略可能かつ未入力の場合、その行全体が出力から消去されます。
* 省略可能変数自体がある行は `((変数名))` を省略しても自動的に行消去の対象になります。
* ※行末の `((...))` 表記自体は、最終的なプロンプト出力から常に自動除去されます。

3. 見出し（#）の自動消去

* ある見出し（# 〜 ######）配下のコンテンツが、変数の未入力によってすべて消去された場合、その見出し自体も自動で消去されます。
* 子見出しがすべて消去され親見出し配下が空になった場合も、親見出しが連鎖して消去されます。
* （固定のテキストやコードブロックが1行でも残っている場合は、見出しが消去されることはありません）

4. 命令行のON/OFF切り替えとリスト仕様

* ハイフン「- 」で始まる箇条書き行: 省略可能（詳細画面のチェックボックスでON/OFFトグル可能・デフォルトON）
* プラス「+ 」で始まる箇条書き行: 省略可能（詳細画面のチェックボックスでON/OFFトグル可能・デフォルトOFF・出力時は「- 」に自動変換）
* アスタリスク「* 」で始まる箇条書き行: 省略不可（固定保護・出力時は「- 」に自動変換）
* 基本は+か-を使用してユーザーの自由を守ってください。*を使うのは間違って消すとプロンプトとして成り立たなくなる、システムプロンプトなどの部分です。
* むやみに、((変数名))が行末にある列だからと+にすると、変数名を指定したのに反映されないプロンプトになるなどの問題が起こるため注意してください。
* 複数行を連動して切り替えさせたい場合は `[BLOCK:タイトル]...[/BLOCK]` で囲んでください。
* AIの返答用JSONフォーマット（```json ... ```）は、誤って除外されないようコードブロックで記述してください（固定保護されます）。

5. テンプレート本文末尾に含める【必須の出力形式指示】
   作成するテンプレート本文の末尾には、アプリへの一括インポートを成功させるため、必ず以下のブロックをそのまま埋め込んでください。前後に余計な解説文や挨拶を含めず、純粋なJSON配列のみを返させる指示とすることが必須です。

【出力形式】
出力は必ず以下のJSON配列のみを出力してください。
Markdownコードブロックで囲んでください。
前後に余計な解説文や挨拶は含めないでください。

```json
[
  {
    "question": "問題文",
    "answer": "解答文"
  }
]
```
