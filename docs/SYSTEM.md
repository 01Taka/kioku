# 📚 FSRS×2段階キュー型 学習システム 仕様書（改訂完成版）

## 1. 全体アーキテクチャ & データモデル

### 1-1. 2階層カテゴリ構造（科目 ＞ 講義回）

大学のシラバス・カリキュラムに完全同期する2階層構造を採用する。

- **第1階層（親: Course / 科目）:** 例: `電気回路I`, `線形代数`
- **第2階層（子: Lecture / 講義回）:** 例: `第1回 オームの法則`, `第2回 過渡現象`
- カードは必ず **第2階層（講義回）** に直接所属する（カードの所属IDは永続固定し、物理移動は行わない）。

### 1-2. 2段階キュー構造（Two-Stage Queue）

- **講義専用プール（短期ステージ）:** 子階層（講義回）単位で動作。文脈の中で20〜30問を一気に短期記憶化する。
- **共通プール（長期ステージ / FSRS）:** 全講義の卒業カードが集約。`ts-fsrs` を用いたインターリーブ（混在）学習で長期定着を管理する。

### 1-3. カードのライフサイクル・ステータス（`phase`）

講義カードの状態（`phase`）は以下の4分類で管理される。

```
[新規カード] ───> UNATTEMPTED（未実施: 一度も取り組んでいない）
                       │
                       │ (チェックモード等で初回回答)
                       ▼
                  UNGRADUATED（未卒業: 取り組んだことがあるが未卒業） <───────────────┐
                       │                                                            │
                       │ (連続2回以上正解)                                          │
                       ▼                                                            │
                  GRADUATION_RECOMMENDED（卒業推奨: 2回以上連続正解中）             │
                       │                                                            │
                       │ (ユーザー操作による一括/個別移動 又は スキップ)             │ 【降格】
                       ▼                                                            │ 手動降格ショートカット /
                  GRADUATED（卒業済: 共通プールへ移動済み） ────────────────────────┘ 「忘れかけ」除外経由
                       │                                                             (consecutiveCorrect=0,
                       │                                                              lastAttemptAt=now)
                       ├── [休止] ──> isSuspended = true (一時除外)
                       └── [再開] ──> isSuspended = false (休止前の phase を完全維持)
```

1. **`UNATTEMPTED`（未実施）:**
   - 過去に一回も取り組んでいない初期状態（`consecutiveCorrect = 0, lastAttemptAt = null`）。
   - 手動リセット操作によってのみこの状態へ戻すことができる。
2. **`UNGRADUATED`（未卒業）:**
   - 取り組んだことがあるが、まだ卒業していない状態（連続正解数 0 または 1）。
   - 不正解となった場合は即座に連続正解数 `0` の未卒業となる。
3. **`GRADUATION_RECOMMENDED`（卒業推奨）:**
   - 現在2回以上連続で正解している状態（`consecutiveCorrect >= 2`）。
   - 自動で共通プールへ移動せず、講義画面や演習結果画面の「卒業推奨を一括移動」ボタン、またはカード個別の卒業ボタンによってユーザーの意図で共通プールへ移動する。
   - 共通プールへ移動する前でも、前回取り組みから規定時間（デフォルト8時間）が経過すればチェックモードの定着確認（優先度3）として出題可能。
4. **`GRADUATED`（卒業済）:**
   - 共通プール（FSRS）へ移動済みの状態。日々の共通復習セッションの対象。
5. **休止フラグ（`isSuspended: boolean`）:**
   - 休止（サスペンド）は単一の `phase` ではなく **各カードの独立フラグ** として管理する。
   - 休止中も元のステータス（`UNATTEMPTED` / `UNGRADUATED` / `GRADUATION_RECOMMENDED` / `GRADUATED`）は保持され、再開時は休止前の状態に完全に復帰する。

## 2. 講義専用プール（短期ステージ）仕様

子階層（講義回）単位で実行される講義カードの学習・確認・演習モード。

### 2-1. 出題形式（2種類）

講義画面には以下の2種類の演習モードを用意する。

1. **✅ チェックモード（状態遷移あり）:**
   - 規定条件を満たす対象カードのみを抽出し、**優先度順（3 > 2 > 1）** に並べて出題する（最大10問のマイクロセッション）。
   - 回答結果（〇/×）に応じてカードの `consecutiveCorrect`、`phase`、`lastAttemptAt` を更新する。
   - 問題が0問の講義はチェックリストに出現しない。
2. **🔁 復習モード（状態変更なし・自由演習）:**
   - 選択された講義のカード（休止中を除く）をシャッフルして出題する（最大10問）。
   - 試験直前の総復習や自由演習用のため、回答してもステータスやFSRSパラメータは一切変更されない。
   - 問題が0問の講義は復習リストに出現しない。

### 2-2. チェックモードの出題対象と優先度（3 > 2 > 1） & 3色カラーコーディング

チェックモードではカードの状態を以下の3つに分類し、**3 > 2 > 1** の優先度順で出題する。
演習画面およびカード一覧では、この3分類に応じて枠線・グラデーション・バッジを色分け表示する。

| 優先度                                           | 条件                                                                                                                                       | 意味・役割                                           | UIカラー                  |
| :----------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------- | :------------------------ |
| **③（最優先）**<br>`PRIORITY_3_COOLDOWN_CLEARED` | 連続1回以上正解（`UNGRADUATED` または `GRADUATION_RECOMMENDED`）かつ、前回の取り組み（`lastAttemptAt`）から規定時間（デフォルト8時間）経過 | **定着確認**<br>時間を空けても覚えているか再確認     | **エメラルド / シアン系** |
| **②（中優先）**<br>`PRIORITY_2_UNATTEMPTED`      | 未実施（`phase === "UNATTEMPTED"`）                                                                                                        | **新規挑戦**<br>まだ一度も触れていない問題           | **インディゴ / ブルー系** |
| **①（後順位）**<br>`PRIORITY_1_ZERO_STREAK`      | 連続正解0の未卒業（`phase === "UNGRADUATED"` かつ `consecutiveCorrect === 0`）                                                             | **弱点リベンジ**<br>直前に間違えてリセットされた問題 | **アンバー / ローズ系**   |

※連続1回以上正解しているカードで、前回の取り組みから規定時間（8時間）が経過していないカードはクールダウン中（ロック）となり、チェックモードの出題対象外となる。

### 2-3. 回答時の状態更新ルール（チェックモード）

- **正解（〇 / Space / →）:**
  - `lastAttemptAt = 現在時刻`
  - `consecutiveCorrect` を `+1` 加算。
    - `consecutiveCorrect === 1` の場合: `phase = UNGRADUATED`（未卒業）。
    - `consecutiveCorrect >= 2` の場合: `phase = GRADUATION_RECOMMENDED`（卒業推奨）。
- **不正解（× / ←）:**
  - `lastAttemptAt = 現在時刻`
  - `consecutiveCorrect = 0` にリセット。
  - `phase = UNGRADUATED`（未卒業）に設定（一度取り組んだため未実施には戻らない）。

### 2-4. 卒業（共通プールへの移動）と個別操作

- **卒業推奨カードの卒業選択:**
  - チェックモード完了時の統一リザルト画面において、新しく卒業推奨（または卒業対象）となったカードを一覧表示し、タップで個別に卒業するか卒業推奨のままとどめるかを選択可能（デフォルト全選択）。画面下部の「n問を卒業」ボタンでワンクリックで `GRADUATED`（卒業済）へ一括移行できる。
  - 講義編集のカード個別三点リーダーメニューからも「カードを卒業」で即時共通プールへ昇格可能。
- **卒業時のFSRS処理:**
  - 共通プールへ移動した瞬間に FSRS の初期パラメータ（`Rating.Good` 相当）をバックグラウンドで作成し、次回期日（`due`）を翌日以降に設定する（当日の共通プールには混入しない）。
- **降格とリセット操作:**
  - 共通プールからの降格時: `phase = UNGRADUATED`, `consecutiveCorrect = 0`, `lastAttemptAt = 現在時刻` となる。
  - 講義画面での「状態をリセット」: 完全初期状態（`UNATTEMPTED`, `consecutiveCorrect = 0`, `lastAttemptAt = null`）に戻す。

## 3. 共通プール（長期ステージ / FSRS）仕様

- **`ts-fsrs` パラメータ設定:**
  - **目標保持率（`request_retention`）:** **`0.82`**（大学の進度と負荷の最適バランス。設定画面で0.70〜0.95で調整可能）。
  - **サブデイ（1日未満）の無効化:** `enable_short_term: false`（ステップ空配列）。復習間隔は**最低1日（翌日以降）**を強制。
- **回答ボタン（レーティング）:**
  - **2ボタン固定（Again / Good）**。
    - 不正解 $\rightarrow$ `Rating.Again`
    - 正解 $\rightarrow$ `Rating.Good`
    - ※`Hard` と `Easy` は内部的にも一切使用しない。
- **例外なしのFSRS通常更新:**
  - 出題されたカードは、通常・優先・強制出題・先取り（パープル）を問わず、すべて通常通り `fsrs.next()` を実行してパラメータを更新する。
- **降格カードの再卒業時データ:**
  - 講義専用プールへ降格したカードが再卒業した際は、過去のFSRS履歴を引き継がず**「完全リセット（新規カード化）」**してスケジュールを再開する。

## 4. カテゴリー優先度制御（3段階 & 階層継承）

親（科目）または子（講義回）単位で、以下の3つの優先度モードを設定可能。

| モード                               | 出題範囲                                   | 特徴・挙動                                                                                                                                                                                                                                                                  |
| ------------------------------------ | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **強制出題**<br>_(超重要・毎日演習)_ | **配下の `GRADUATED` 全カード（due無視）** | ・期日に関係なく、その講義の卒業済カードが毎日最優先で出現。<br>・**同じカードは1日に1回しか出題されない（1回解いたら当日は完了）**。<br>・パープルも含めて全問シャッフル。<br>・その日の強制出題カードを解き終えた後は、他講義の「優先」「通常」カードが順番に出題される。 |
| **優先**<br>_(小テスト・苦手)_       | **期日到来カードのみ**                     | ・当日解くべきカードの中で、その講義のカードを最優先出題。<br>・未来のカード（期日前）は出題されない。                                                                                                                                                                      |
| **通常**<br>_(平時)_                 | **期日到来カードのみ**                     | ・通常のFSRS出題順序に従う。                                                                                                                                                                                                                                                |

- **強制出題カードの出題・消化判定:**
  - **出題条件:** `phase === GRADUATED` かつ `isSuspended === false` かつ **`lastReviewedAt < 日界日時`（または未レビュー）**。
  - **出題後:** 1回解いたら通常通りFSRSを更新し、`lastReviewedAt = now` となるため当日の共通プールからは消える。翌日の日界を過ぎると再びキュー最優先に出現する。
- **階層継承ルール:**
  - **親（科目）で一括設定可能:** 親を「強制出題」に設定すると、配下の全講義回が一括で強制出題となる。
  - **子（講義回）での個別上書き可能:** 親が「通常」でも、特定の子（例: `第3回`）だけを「優先」に上書き可能。
- **複数指定時の合流・出題順序:**
  1. 「強制出題」に指定された全講義の当日未学習カード（合算してシャッフル出題）
  2. 「優先」に指定された全講義の当日到来カード
  3. 「通常」の全講義の当日到来カード
  4. パープル枠（先取りON時、不足分を補充）

## 5. 日々の学習セッション & UI/UX仕様

- **10問区切りのマイクロセッション:**
  - 出題は「10問単位」で実施。10問終了ごとにブレイク・統一リザルト画面を表示。
  - 「次の10問」「終了する」を自由に選択可能。
  - **端数の扱い:** 出題可能なカードが10問未満の場合、パープル設定がOFFならその端数枚数でセッション終了（パープルONなら不足分をパープルから補充）。出題対象が0問の場合はホームメインの「はじめる」ボタンがdisabled（非活性）となる。
- **共通プールの絶対除外フィルタ（重複出題の完全防止）:**
  - いかなるモード・色であっても、**`lastReviewedAt >= 日界日時`（本日すでに1度でも回答・卒業したカード）は当日の共通プールから完全除外**する。
  - これにより、本日卒業したカードが同日セッションにパープル枠として誤混入することや、通常カードが同日中に2度出題されることを防ぐ。
- **3色のカラーコーディング & 厳格な判定優先度:**
  - 🔁 **オレンジ（最優先）:** 直近の学習セッションで間違えて、まだ再正解（Good）していないカード（リベンジ枠）。
  - 🎯 **グリーン（通常）:** 今日が最適 または 期限切れの通常カード。
  - ⚡ **パープル（先取り）:** 未来に期日があるカード（全先取りカードが対象）。
  - **【色判定ロジックの評価順序（上から評価）】**
    1. `isOrange === true` $\rightarrow$ **オレンジ**（期日が翌日以降でもオレンジを最優先）
    2. `due < 本日の日界日時` $\rightarrow$ **グリーン（期限切れ）**
    3. `本日の日界日時 <= due < 翌日の日界日時` $\rightarrow$ **グリーン（当日分）**
    4. `due >= 翌日の日界日時` $\rightarrow$ **パープル（先取り）**
- **パープル（先取り）の出題 & メッセージ表示仕様:**
  - **出題順序:** `due` が近い順（昇順）にキューへ補充される。
  - **設定:** アプリ設定（設定モーダル）でON/OFF切り替え可能。
- **出題順のソート設定（ユーザー選択可能）:**
  - **[A] due順にソート:** 期日が古い順に出題。
  - **[B] カテゴリ内シャッフル:** オレンジ・グリーンはシャッフル、パープルはdue順（強制出題カードは完全シャッフル）。
- **日付変更線（日界）:**
  - 毎日午前00:00（設定により変更可能）。

## 6. 誤答（Again）処理 & 「今日間違えた問題」画面

- **セッション内ループの完全廃止:**
  - 共通プールでミス（Again）してもセッション内での再出題は一切行わない。
  - ミスしたカードは `isOrange = true` となり、次回以降のセッションで「オレンジ（リベンジ枠）」として最優先出題される。
- **連続ミス回数のカウント仕様:**
  - **加算:** 共通プールで出題され、回答ボタンで **`Rating.Again` を選択するたびに `consecutiveFailCount += 1`**。
  - **リセット:** 次回以降の共通プールで **`Rating.Good`（正解）した瞬間**、または講義専用プールへ **降格した瞬間** に `consecutiveFailCount = 0` および `isOrange = false` にリセット。
- **振り返りハブ ＆ 手動降格ショートカット:**
  - ホームの「今日のミス」画面や演習結果画面（統一リザルト画面）等にミスした問題一覧を表示（`科目名 > 講義回名` のパンくずを表示）。
  - 各カードに「連続ミス回数バッジ」（例: `⚠️ 2連続ミス`）を表示。
  - ホームの「今日のミス」からはミス問題に絞ったリベンジ演習（10問〜全問）を即座に開始可能。
  - 演習結果画面では、ミスしたカードをその場で「n問を復習」ボタンで再挑戦するか、または講義専用プールへ手動で戻す（降格させる）選択が可能。

## 7. 忘れかけ（想起確率 $R < 0.35$ ベースのサボり救済）

- **目的:** 数週間アプリを開けず、復習が溜まりすぎた場合の救済・トリアージ領域。
- **抽出条件:** 想起確率 **$R < 0.35$**（記憶が著しく低下したカード）が1枚以上ある場合。
- **挙動 & UI統合:**
  - ホーム画面のサブタブ **「忘れかけ」** に統合され、タブ横のバッジで該当カード件数を表示。
  - 不要な警告バナー等で通常学習画面を圧迫せず、ユーザーが明示的にタブを開いた際に落ち着いて整理・除外できる。
- **提供するアクション:**
  - 所属情報（`科目名 > 講義回名`）とともに問題文・現在の記憶維持率（%）を一覧表示。
  - チェックボックスで個別選択して **「選択した問題を除外」**、または **「すべて除外」** をワンタップで実行可能。
  - ※除外を実行したカードは共通プールから外れ、所属する講義専用プールへ **「未卒業（連続正解0）」** として戻り、講義チェックで再特訓を受けられる状態になる。

## 8. 一括操作 & 管理機能

- **講義・科目の一括休止（サスペンド）と状態復元:**
  - 親（科目）または子（講義回）単位で「休止 / 再開」を切り替え可能。
  - **休止時:** 配下の全カードの `isSuspended = true` に設定。
  - **再開時:** 配下の全カードの `isSuspended = false` に設定。
  - ※カードの `phase`（`UNATTEMPTED` / `UNGRADUATED` / `GRADUATION_RECOMMENDED` / `GRADUATED`）や連続正解数、FSRSパラメータは一切変更されないため、**休止前の学習進捗状態が100%完全に復元**される。
- **進捗表示（プログレスバー）:**
  - 教材一覧画面では、テキスト数値を並べて画面を圧迫することを防ぎ、**3色のプログレスバー（卒業済み: エメラルド / 現在チェック可能: アンバー / それ以外: スレート）のみ** をシンプルに表示（バーにホバー時のツールチップで各枚数を確認可能）。
- **演習結果（リザルト画面）の統一UI:**
  - ホームメイン、今日のミス、教材チェック、教材復習のすべての演習終了時モーダルで同一のUIフォーマット（`PracticeResultView`）を採用。
  - 上部に大きく `正解数 / 問題数 (n / m)` を表示し、その下に状況に応じた動的メインアクションボタンを配置。
  - 下部に「わからなかった (n問)」「卒業 (x問) ※チェック時のみ、選択可能」「わかった (m問)」の3セクションで問題リストを展開。
